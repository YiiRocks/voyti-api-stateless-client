# Voyti API Stateless Client

Stateless, SPA-friendly JSON API for [Voyti](https://github.com/YiiRocks/voyti), the Yii3 user-management
extension: credential-based login issuing bearer tokens, account/session self-service, RBAC admin,
and audit-log endpoints, built on [Voyti API](https://github.com/YiiRocks/voyti-api)'s token
authentication. 2FA, social-login, and GDPR endpoints activate automatically when the corresponding
optional Voyti sibling package is installed — no extra configuration required.
